Exchange with Multiple Parties

This Simulation

In this simulation, multiple parties are introduced. Utilities have the same function form for all agents (Cobb-Douglas), but coefficients are randomized, so that agents have different preferences. Endowments are also randomized at the beginning of the simulation. Agents are represented by balls, the size of which is proportional to their utility. When agents find partners, their color changes to indicate good or bad trades. If an agent fails to trade with every other agent, it will be dimmed down and will stop trading.

Agents will find exchange partners using the method selected below: by exhausting the list of agents and finding the best partner; by randomly selecting a partner and accepting the first good trade; or by trading with the agents that "bump" into. The order that agents trade is randomized in all cases.
